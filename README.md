# CineVault - Movie Portal

**Live Site:** [https://cinevault-demo.appspot.com](https://cinevault-demo.appspot.com)

CineVault is a premium cinematic database designed for movie enthusiasts to discover, track, and curate their personal movie collections. The portal provides a responsive and dynamic user interface powered by modern web technologies.

## ✨ Key Features

* **Discover & Search:** Browse through an expansive collection of movies with a powerful real-time search algorithm allowing fast discovery.
* **Featured Hits:** A dynamic Home page featuring a beautiful static slider and a tailored "Featured Movies" section presenting the top 6 highest-rated entries.
* **Authentication & Profiles:** Secure Firebase user authentication enabling email/password registration with strict validations and one-click Google Sign-In.
* **Personalized Vaults:** Users can add, update, and delete movies with a 50-year backwards-compatible release year selection and a star-based rating system. 
* **Favorites System:** Users can save their favorite cinematic masterpiece into a dedicated "My Favorites" private route displaying custom 3-column curated grids.
* **Premium UI & Dark Mode:** Hand-crafted Tailwind CSS interfaces highlighting aesthetic movie cards, integrated Toast notifications (no default alerts), and an intuitive interactive Dark/Light theme challenge built-in.

## 🚀 Built With

* **Frontend:** React (Vite), React Router v6, Tailwind CSS v3 (configured), React Hook Form, React Toastify, React Simple Star Rating.
* **Backend:** Node.js, Express.js.
* **Database & Auth:** MongoDB Atlas, Firebase Authentication.
