## 🌟 Overview

**CineVault** is a modern and immersive movie portal built for cinema enthusiasts who love discovering, organizing, and managing their favorite movies in one place. With a sleek user interface, secure authentication, personalized favorite collections, and powerful movie management features, CineVault delivers a premium movie browsing experience.

Whether you're searching for blockbuster hits, maintaining a personal watchlist, or contributing your favorite movies to the community, CineVault provides everything in a beautiful and responsive environment.

---

## 🚀 Features

### 🎥 Explore Movies

* Browse a growing collection of movies submitted by users.
* View detailed movie information including poster, genre, duration, rating, release year, and summary.
* Search movies instantly by title.

### ⭐ Featured Movies

* Dynamic homepage featuring the **Top 6 Highest Rated Movies**.
* Beautiful movie cards with quick access to detailed information.

### 🔐 Secure Authentication

* Firebase Email & Password Authentication.
* Google Sign-In Integration.
* Protected Routes for authenticated users.
* Persistent login state after page refresh.

### ❤️ Personal Favorites Vault

* Save your favorite movies with one click.
* Manage your own personalized movie collection.
* Remove movies from favorites whenever you want.

### ✏️ Full Movie Management

* Add new movies to the platform.
* Update movie information.
* Delete movies when necessary.
* Form validation using React Hook Form.

### 🌙 Modern User Experience

* Fully Responsive Design.
* Interactive Dark & Light Theme Toggle.
* Toast Notifications for all CRUD operations.
* Custom Loading Spinner.
* Attractive UI built with Tailwind CSS.
